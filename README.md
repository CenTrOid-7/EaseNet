
# EaseNet

EaseNet is a lightweight deep learning library built from scratch using Python and NumPy.  
It implements neural network components to explore the fundamentals of deep learning, backpropagation, and optimization.

## Features

- Dense neural network layers
- ReLU and Softmax activation functions
- Backpropagation
- Optimization algorithms:
  - Stochastic Gradient Descent (SGD)
  - Momentum
  - Adam
  - RMS-style optimization
- Categorical cross-entropy loss
- L1 and L2 regularization
- Mini-batch training
- Training loss and accuracy tracking
- Model evaluation

## Tech Stack

- Python
- NumPy
- Matplotlib
- Pandas

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/EaseNet.git
cd EaseNet
```

Install the dependencies:

```bash
pip install numpy matplotlib pandas
```
